Why the two directions matter: the spec is written first against mockups (outside-in TDD), so implementation happens behind a frozen contract. But the suite runs lowest-first, so when something breaks, the cheapest tier that fails names the culprit layer — you never start from a full-stack stack trace.

The first feature commit in the repo's history (day 2) was the acceptance layer itself — 13 feature files before most production code existed.

Testing
One class of seam — everything else runs real

Runs real

  • Cucumber scenarios over real HTTP one @SpringBootTest(RANDOM_PORT) context
  • JTE server-side rendering 35 templates, precompiled & typed against DTOs — view bugs fail the build
  • Controllers, services, domain logic real orchestration, real state machine
  • SQLite + Flyway real file DB in Tier 1 & acceptance · 19 migrations, recursive CTEs
constructor-injected io ports

Scriptable stand-ins (@Primary @Profile("test"))

  • ScriptableLlmClient the LLM — scripted from Gherkin, with a spy asserting what the model was not shown
  • ScriptableImageDescriber vision captions
  • ScriptableShortcutClient Shortcut API
  • ScriptableGitHubClient the gh CLI
  • Fixed Clock & FailingCommentRepository frozen time · one-shot fault injection over the real repo

No MockK, no Mockito — not even as a dependency. A test that seems to need a second seam class is treated as “a design smell to discuss, not to push through.” The pattern extended cleanly three times (vision → Shortcut → GitHub), each landing behind its own port on the same template.

Testing
One gate command — and CI is the same command
docker compose run --rm build→ verifyAll→ jsTest→ mcp gates→ tier0→ tier1→ tier2→ acceptance

CI == local

The GitHub Actions workflow is ~25 lines and its only build step is the same Docker command a developer runs. No matrix, no cache config — “passes locally, fails in CI” is structurally impossible for the Docker path.

Red-first machinery

Specs can land ahead of code tagged @wip (filtered from the gate); discovery mode (-Pdiscovery=true) lets a sea of red run without aborting while scaffolding. Today: zero @wip tags — the spec is fully green.

Honest print: ./gradlew verifyAll is also wired into check, the default test task is disabled, and since 2026-07-10 compose runs the image’s verifyAll default (no stage list to drift), acceptance enforces an executed-scenario floor from report.json, and Node ≥ 21 is declared + preflighted. Still true: the merge gate is convention (no branch protection yet) and tier ordering is advisory.

For a human

  • ✓

    Failures self-localise. The lowest tier that fails names the broken layer — debugging starts at a millisecond test.

  • ✓

    No mock DSL to learn. Every double is ordinary Kotlin you can step through; failure injection is a Gherkin one-liner.

  • ✓

    The spec teaches the product. Feature files + dated decision blocks beat most staffed teams’ onboarding docs.

  • ✓

    Redesigns are cheap. Restyling can’t break 153 scenarios — proven three times in one review cycle.

  • ✗

    Doctrine docs can drift. Five live drifts fixed 2026-07-10; safe only while the standing audit (plan_docs/docs-drift-audit.md) keeps running.

  • ✗

    On-repo context needs feeding. Cross-session state now lives in context.md (2026-07-10), but nothing enforces that sessions keep it current.

  • ✗

    Green could lie in three places — all closed 2026-07-10 (scenario floor, Node ≥ 21 preflight, mcp/ gated). Residual: the merge gate is still convention, no branch protection.

For an AI agent

  • ✓

    Ground truth beats hallucination. The executable spec pins even invisible contracts — “the model’s context contained no vote signal.”

  • ✓

    A verification gradient sized to the iterate loop: ms → s → one Spring context. The deterministic LLM double makes an LLM app hermetically checkable.

  • ✓

    Skills = retrieval-free context for exactly the knowledge code can’t reveal, auto-loaded at the right path.

  • ✓

    Plan docs = cross-session memory. A fresh session resumes from the status header; parallel sessions pre-claim resources in writing.

  • ✗

    Convention volume taxes context. Touching acceptance can mean two ~350-line skills + feature file + plan doc + requirements §.

  • ✗

    Stale snippets breed confident mistakes — an agent reproduces the deprecated pattern, and the next agent copies it.

  • ✗

    Tier discipline is honor-system. Membership is a @Tag; every tolerated exception becomes a precedent to pattern-match.
